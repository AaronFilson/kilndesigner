# Olsen 100 cu ft kit (`olsen-kit-100`)

The biggest Olsen gas updraft kit the book gives flues for. Design file:
`examples/olsen/olsen-kit-100.yaml`.

## Sources

Olsen, *The Kiln Book*, 4th ed.: p.174 (text: inlet and exit areas); the kit family pp.169–176,
p.222, p.235; Fig 6-63 (p.172) for floor-burner placement in updrafts. No figure of this kiln.

## Key results

108 ft³; heat loss 26.8 kW; Ward's input 1.08 million BTU/hr against 1.5 million from twenty
MR-750s; arch frame L4×4×¼.
