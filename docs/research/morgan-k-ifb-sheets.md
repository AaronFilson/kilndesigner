# Morgan / Thermal Ceramics K-series IFB: three data sheets in full

Transcribed 2026-11-09 from PDFs supplied by the owner (kept locally, not in the repo). Every value
below is as printed, with the sheet's own units, signs and typos; "-" means the sheet prints a dash
(no value). All three sheets state the values are "typical average values", subject to normal
manufacturing variation, "not ... for specification purposes".

- **[K1]** Thermal Ceramics (Morgan Crucible), *K-23, TC-23, IFB 23 Tile, K-25*, Datasheet Code
  US 114-3, MSDS code US 151-1, 02:2010, 2 pp. (file `114-3-data-sheet-k23 & k25 brick.pdf`).
  Same as `refractory-bearing.md` [B21].
- **[K2]** Morgan Thermal Ceramics, *IFB up to 2600°F (1427°C): K-23, TC-23, K-23-HS, K-25, K-26*,
  Datasheet Code US 1-14-3, updated 02/2016, 2 pp. (file `199290_DATA-TC-114-3.pdf`).
  Same as `refractory-bearing.md` [B22].
- **[K3]** Morgan Thermal Ceramics, *K Insulating Firebrick Series*, Code BR.02, 1 January 2025, 2 pp.
  (file `k-ifb-series_eng.pdf`). https://www.morganthermalceramics.com/media/0wobjak3/k-ifb-series_eng.pdf
  Same document as `refractory-bearing.md` [B10], `electric-and-thermal.md` [S31], `flat-roofs.md` [F11].

## 11. What this changes elsewhere

- `materials.yaml` `ifb-k23`, `ifb-k25`, `ifb-k26` match [K3] (2025). Their conductivity and density
  are unchanged; `ifb-k23`'s `status: excerpt` could become `verified` now that [K3] has been read
  directly. Not changed in this pass (engine data, engine-v2 decisions apply).
- K-26's 2016 conductivity is lower than the 2025 values the library uses. The library keeps the
  current sheet.
- New grades with no library entry: TC-23, IFB 23 Tile, K-23 HS, Insalcor.
- Reheat shrinkage (§6) and hot-load deformation (§5) are now on file for K-23, TC-23, K-25, K-26
  (shrinkage only) and K-23 HS (shrinkage only).
